# 특별실 예약

선생님들은 **로그인 없이** 링크만 열어 소속·이름을 적고 예약합니다. 관리자만 이름+PIN으로 들어갑니다.

구조: **화면(web/)은 일반 웹 주소**, **데이터는 구글 시트 + Apps Script(JSON API)**.
화면이 Apps Script 밖에 있어서 교사들의 구글 계정 상태와 무관하게 열립니다.

## 1. 구글 시트 + Apps Script 만들기
1. 새 구글 스프레드시트를 만든다. (이름 예: `특별실예약DB`)
2. `확장 프로그램 → Apps Script` 를 연다.
3. `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장한다.
4. 함수 선택 칸에서 `setup` 을 골라 **실행**한다. (처음 한 번 권한 승인 필요)
   → 시트 7개(공간·교시·학기·수업잠금·사용자·예외일·예약)와 예시 데이터가 생긴다.
5. `배포 → 새 배포 → 유형: 웹 앱`
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 `.../exec` 주소를 복사한다.
6. 코드를 고칠 때마다 `배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포` (주소는 그대로 유지됨).

## 2. 시트 내용 채우기
- **공간**: 공간ID(R1, R2…), 이름, 위치, 사용여부(Y/N)
- **학기**: 학기ID, 이름, 시작일, 종료일 (시간표 개편 때 새 줄 추가)
- **사용자**: 관리자만 적는다. 이름, PIN, 권한(`관리자`). **예시 PIN(0000)은 반드시 바꿀 것.**
- 교시, 수업 잠금, 예외일은 웹 화면의 "관리자 설정" 탭에서 입력한다.

## 3. 화면 올리기 (GitHub Pages)
1. `web/config.js` 의 `API_URL` 에 위의 `.../exec` 주소를 붙여 넣는다.
2. `web/` 폴더 내용(`index.html`, `config.js`, `emblem.png`)을 GitHub 저장소에 올리고 `Settings → Pages` 에서 켠다.
3. 나온 주소를 교사들에게 공유한다.

## 4. 로컬에서 미리 보기
`API_URL` 을 비워 둔 채 `web/index.html` 을 서버로 열면 가짜 데이터(모의 모드)로 동작한다. (관리자 이름 `관리자` / PIN `0000`)

## 사용 방법
- **선생님**: 링크 접속 → 소속·이름 입력(기기에 기억됨) → 빈 칸 선택 → 사용 목적 입력 → 예약하기.
  - 2~3교시처럼 이어서 쓰려면 칸을 여러 개 누르거나(컴퓨터는 세로로 끌어서) 선택한 뒤 한 번에 예약한다. 한 번에 예약한 칸은 하나의 행사로 묶여 화면에서도 합쳐져 보이고, 취소할 때 "이 칸만 / 이 날 행사 전체 / 전체"를 고를 수 있다.
  - "매주 반복"을 켜고 종료일을 고르면 같은 요일·교시를 주마다 예약한다. 수업·다른 예약과 겹치는 날은 건너뛰고 결과에 알려 준다.
  - 취소는 내 예약(초록)을 누르거나 "내 예약" 목록에서 한다. 반복 예약은 "이 날짜만 / 반복 전체"를 고른다.
- **관리자**: 화면 맨 아래 "관리자 로그인" → "관리자 설정" 탭에서 수업 시간표, 예외일, 교시를 편집. 다른 사람의 예약도 취소할 수 있다.

## 알려 둘 점
- **본인 확인은 소속·이름이 같은지로만 한다.** 로그인이 없으므로 다른 사람이 같은 소속·이름을 적으면 그 사람의 예약을 취소할 수 있다. 학교 내부용 신뢰를 전제로 한 방식이다. 잘못된 예약은 관리자가 취소한다.
- 예약 시트에는 소속·이름·목적이 남는다. 링크를 아는 사람은 시간표와 예약자 이름을 볼 수 있다. 예약 목적에 학생 정보 등 민감한 내용을 쓰지 않도록 안내한다.
- 관리자 PIN은 시트에 그대로 저장된다(시트 편집 권한자는 볼 수 있다).
- 예약은 평일만, 오늘부터 60일 이내(`Code.gs`의 `MAX_ADVANCE_DAYS`)만 가능하다. 지난 시간·수업 시간·이미 예약된 칸은 서버에서 막는다.
- 취소는 시트에서 행을 지우지 않고 상태를 `취소`로 바꾼다.
- **예외일**: 그날은 수업 잠금이 풀려 빈 시간이 된다(시험기간·행사 등). 공간을 비워 두면 모든 공간에 적용된다.
- 이미 예전 구조의 `예약` 시트가 있다면(열이 다름), 시트를 지우고 `setup`을 다시 실행한다.
